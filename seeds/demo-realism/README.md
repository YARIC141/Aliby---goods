# Демо-наполнение витрин Alliby

Генератор SQL, который приводит все видимые заведения к «боевому» виду:
ассортимент с описаниями и фото, КБЖУ у еды, услуги с длительностью,
аренда, мастера/тренеры с личными графиками и ценами, абонементы,
зоны доставки, предзаказ и расписание работы на год вперёд.

## Как запустить

```bash
node seeds/demo-realism/build.js          # соберёт seed_all.sql рядом с репозиторием
ssh -p 2222 root@<vps> "docker exec -i supabase-db psql -U postgres -d postgres -v ON_ERROR_STOP=1" < seed_all.sql
```

Весь SQL обёрнут в `BEGIN/COMMIT` — при любой ошибке не применится ничего.

## Принципы

- **Идемпотентность.** Позиции и категории заводятся по паре `(store_id, name)`:
  сначала `INSERT ... WHERE NOT EXISTS`, потом `UPDATE`. Пересоздавать записи
  нельзя — `order_items.menu_item_id` объявлен `ON DELETE RESTRICT`, на старых
  id висят заказы и брони.
- **Мусорные названия чиним переименованием** (`rename`/`renameCat`) до upsert'а,
  иначе получился бы дубль.
- **Фото только из проверенного пула** `img_results.txt` (Unsplash, каждый id
  реально отдаёт 200). Неизвестный ключ роняет сборку, а не витрину.
- **Мастера** — это `profiles` с `role='employee'`, `employee_store_id`,
  `is_master=true`; услуги привязываются через `master_services`, часы — через
  `master_schedules` (`day_of_week` в конвенции JS `getDay()`, 0 = воскресенье).

## Файлы

| Файл | Что делает |
|---|---|
| `lib.js` | категории, позиции, группы опций, правила цены по времени |
| `lib_master.js` | мастера/тренеры, их графики и персональные цены |
| `lib_sched.js` | `store_schedules` на 400 дней вперёд, праздники и сокращённые дни |
| `v_food.js` | Бургерная «Грильяж», Демо Кофейня |
| `v_goods.js` | ТехноМаркет, Аптека «Здоровье» |
| `v_services.js` | Барбершоп «Стриж», FitLife, Студия красоты «Жемчуг» |
| `v_sport_ent.js` | КНТС, Компьютерный клуб Apex |
| `extras.js` | координаты, зоны доставки, предзаказ, абонементы, расписание, уборка тестовых заведений |
